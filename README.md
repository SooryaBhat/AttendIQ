# 🎓 AttendIQ – AI-Powered Attendance ERP

AttendIQ is an AI-powered Attendance Management and Academic ERP platform designed for educational institutions. It streamlines attendance tracking using Face Recognition, Voice Recognition, QR Attendance, and real-time analytics while providing role-based access for administrators, faculty, and students.

## 📸 Project Overview

AttendIQ provides a complete attendance ecosystem for institutions with:

- AI-based Face Recognition Attendance
- Voice Recognition Attendance
- QR Code Attendance
- Real-Time Attendance Analytics
- Attendance Reports & Insights
- Role-Based Dashboards
- Student Subject Enrollment
- Faculty Session Management
- Department Administration
- Super Admin Controls

---

## 👥 User Roles

### 🛡️ Super Admin
- Manage departments
- Manage department admins
- Institution-wide analytics
- System reports and monitoring

### 🏢 Department Admin
- Manage students
- Manage faculty
- Manage subjects
- Department-level reports

### 👨‍🏫 Faculty
- Create attendance sessions
- Generate QR attendance
- View enrolled students
- Track attendance statistics

### 👨‍🎓 Student
- Join subjects using code/QR
- Mark attendance
- View attendance records
- Access personal dashboard
